# 콘텐츠 스튜디오

**분야만 정하면** 블로그 글, 인스타그램 카드, 쓰레드 글을 만들어 주는 내 컴퓨터용 프로그램이에요. 주제를 고르면 Claude가 리서치 → 초안 → 자동 점검 → 인스타 카드 → 쓰레드 글까지 만들어요. 나는 주제를 고르고, 읽어 보고, 붙여 넣기만 하면 돼요.

> **처음 설치한다면** → [설치 안내서](https://claude.ai/code/artifact/6b0f2b64-193c-4a95-95d2-df97f90cc4dc)를 따라 하세요. 준비물, Mac·Windows 설치, 첫 설정, 문제 해결까지 순서대로 정리되어 있어요.

개인이 만든 무료 프로그램이에요. Anthropic(Claude), Meta(인스타그램·쓰레드), 네이버와는 관계없어요. [MIT 라이선스](LICENSE)라 자유롭게 고쳐 쓰고 나눠도 돼요.

## 준비물

- Claude 유료 구독(Pro 또는 Max)과 Claude Code. 구독료 외에 추가 비용은 없어요. API 키도 필요 없어요.
- Node.js 18 이상
- Google Chrome(Mac) 또는 Microsoft Edge(Windows): 인스타 카드 이미지를 만들 때 써요.

Claude에 API 키 방식으로 로그인돼 있으면 요금이 따로 나갈 수 있어요. 터미널에서 `claude`를 실행한 뒤 `/login`으로 구독 계정에 로그인해 두세요. 프로그램은 실행할 때 `ANTHROPIC_API_KEY` 환경변수를 지우고 구독으로 돌려요.

## 설치와 실행

화면을 보며 차근차근 따라 하려면 [설치 안내서](https://claude.ai/code/artifact/6b0f2b64-193c-4a95-95d2-df97f90cc4dc)를 보세요. 아래는 요약이에요.

**Mac** (터미널에서 이 폴더로 이동한 뒤)
```bash
zsh scripts/setup-mac.sh      # 필요한 프로그램과 로그인 확인
zsh scripts/make-mac-app.sh   # "콘텐츠 스튜디오.app" 만들기 (선택)
```
`콘텐츠 스튜디오.app`이나 `start.command`를 더블클릭하면 앱 창이 열려요. 끌 때는 `stop.command`. 터미널에서는 `npm start` 후 http://localhost:4600 을 열어요.

**Windows**: `install.bat`을 더블클릭한 뒤 바탕화면의 **콘텐츠 스튜디오**를 열어요. 자세한 내용은 `README-WINDOWS.md`를 보세요.

## 처음 설정 (6단계, 한 번만)

1. 환영 → 2. 연결 확인(Claude 로그인, 브라우저)
3. **분야 정하기**: 예시 12개(AI·업무 자동화, 경제·재테크, 여행, 요리·맛집, 육아·교육, 반려동물, 운동·건강, 책·자기계발, 스포츠, 영화·드라마, 게임, 패션·뷰티) 중에서 고르거나 직접 입력해요. 세부 분야 2~4개, 독자, 내 관점을 고쳐 쓸 수 있어요.
4. **글쓴이·말투**: 글쓴이 이름(실명 말고), 인스타 계정, 말투(평서체·존댓말·합니다체)
5. **문체 샘플**(선택): 예전 글 주소(네이버 블로그 주소면 최근 글 10편)나 이 컴퓨터의 파일·폴더 경로를 넣어 가져오거나, 본문을 붙여 넣어요. 최대 20편이고, **내가 쓴 글만** 넣어 주세요.
6. **확인·고정**: 맞춤 규칙 만들기가 바로 시작돼요(5~10분).

분야는 **처음에 정하면 바꾸지 않아요.** 그 분야에 맞춰 규칙을 만들기 때문이에요. 다른 분야도 쓰고 싶으면 이 폴더를 통째로 복사하고 `config.json`의 `port`를 다른 숫자로 바꿔 따로 설정하세요. 고정한 뒤에도 글쓴이 이름, 인스타 계정, 뉴스레터 주소, 카드 색은 설정 화면에서 바꿀 수 있어요.

## 글 한 편 쓰는 순서

1. **주제 정하기**: "추천 주제 받기"를 누르면 요즘 소식으로 주제 12개를 세부 분야에 고르게 나눠 골라 줘요. 직접 입력해도 돼요. 한 줄 관점을 적으면 그 관점으로 써요.
2. **기다리기**: 한 편에 보통 10분 안팎. 홈에서 단계별 진행이 보여요.
3. **검수함**: 초안을 읽고, 자동 점검의 "출처 1곳", "확인 필요"를 출처 링크로 확인한 뒤 승인하거나 수정 요청을 적어요.
4. **발행**: 제목·본문·태그·캡션·쓰레드 글을 복사해 붙여 넣고, 카드 이미지를 올려요. 블로그 주소를 넣으면 쓰레드 마지막 글에 링크가 채워져요.
5. **뉴스레터**(선택): 최근 7일 동안 승인한 글로 주간 노트를 만들어요.

### 진행 방식 고르는 법

| 진행 방식 | 이런 글에 |
|---|---|
| 리서치 후 글쓰기 (추천) | 요금·기능 비교, 법·제도처럼 숫자와 사실이 중요한 글 |
| 한 번에 쓰기 (빠름) | 개념 설명, 가벼운 글 |
| 리서치만 하고 저장 | 나중에 쓸 주제 |
| 조사 없이 내 메모로 쓰기 | 내 경험·생각 위주의 글 |

주제 4개로 시험해 보니 두 방식의 글 품질은 비슷했고, 한 번에 쓰기가 사용량은 약 3분의 1 적고 24% 빨랐어요. 다만 숫자가 많은 주제에서는 한 번에 쓰기가 출처와 다른 내용을 더 자주 썼어요. 채점도 Claude가 했으니 참고용으로 봐 주세요.

## 이렇게 동작해요

```
처음 한 번: 분야 정하기 → 고정 → AI가 그 분야 맞춤 규칙을 만든다(brand/ 폴더)
글마다    : 주제 → 리서치 → 초안 → 인스타·쓰레드 → (내가) 검수 → (내가) 붙여 넣기
```

1. **분야를 고정하면 맞춤 규칙이 생겨요.** `studio-setup` 스킬(Claude에게 주는 작업 지시서)이 그 분야의 믿을 만한 출처, 저작권·금지 표현, 잘되는 제목 틀, 문체 기준, 인스타·쓰레드 형식, 글 종류(콘텐츠 기둥) 4~6개를 조사해 `brand/`에 파일로 써요. 문체 샘플을 넣었다면 줄 길이와 연결어 빈도를 세어 내 말투를 따라 해요.
2. **글은 단계를 나눠 써요.** 리서치(웹 검색) → 초안(웹 검색 없이 리서치 기록만 근거로) → SNS. 단계마다 Claude를 따로 실행하고, 프로그램이 결과 파일을 확인한 뒤 다음 단계로 넘겨요.
3. **AI는 판단과 글쓰기만, 나머지는 코드가 해요.** 작업 순서, 파일 확인, 카드·도표 이미지, 사진 라이선스 확인, 금지 부호 점검은 코드가 맡아요.
4. **피드백이 규칙이 돼요.** 화면의 "의견 남기기"에 적은 말은 `brand/feedback.md`에 쌓이고, 모든 단계가 가장 먼저 읽어요.

## 폴더

| 경로 | 무엇 |
|---|---|
| `.claude/skills/` | 단계별 작업 지시서(스킬). `studio-setup`, `studio-topics`, `studio-research`, `studio-draft`, `studio-revise`, `studio-social`, `studio-newsletter`, `studio-intake`, `studio-onepass`, `studio-judge` |
| `brand/` | 처음 설정에서 만들어지는 내 분야 규칙(브랜드, 문체, 채널, 리서치·저작권, 글 종류, 피드백, 문체 샘플). Git에 올라가지 않아요 |
| `data/` | 내 설정과 결과물(주제 묶음, 글, 리서치 기록, 로그). Git에 올라가지 않아요 |
| `lib/` | 서버 부품: 작업 순서, Claude 실행, 카드 이미지, 사진, 메일 |
| `public/` | 화면 |
| `scripts/` | 설치·실행·예약, 비교 실험(`compare.js`) |

## 두 진행 방식 직접 비교하기

같은 주제를 두 방식으로 만들고, 누가 만들었는지 가린 채로 채점해요.

```bash
node scripts/compare.js "비교할 주제"
```

결과는 `data-compare/<실험 id>/report.md`에 남아요. Claude 실행 횟수, 시간, 토큰, 출처 2곳 확인 비율, 자동 점검 결과, 눈가림 채점(사실 근거·출처 확인·독자 이해·문체·구성·SNS)을 나란히 보여 줘요. 글 두 편과 채점까지 하니 구독 사용량이 넉넉할 때 돌리세요.

## 메일로 주제 보내기 (선택)

휴대폰에서 정해진 제목으로 메일을 보내 두면, 화면의 **지금 메일 확인**을 누를 때 그 메일로 글을 만들고 다 되면 결과물을 회신해요. 설정 → 메일로 주제 받기에서 Gmail 주소, 앱 비밀번호(Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호), 보낸 사람 주소, 제목에 들어갈 말을 저장하세요. 읽기 전용으로 접속하고, 앱 비밀번호는 이 컴퓨터의 `data/secrets.json`에만 남아요.

## 알려진 한계

- 블로그·인스타그램·쓰레드 게시는 복사해서 붙여 넣는 방식이에요. 네이버는 공식 글쓰기 API가 없어요.
- 사진은 저작권 때문에 위키미디어 커먼즈의 자유 라이선스 사진과 직접 올린 사진만 써요.
- AI는 수치를 잘못 읽을 수 있어요. 출처 링크로 확인하는 검수 단계를 빼지 마세요.
- 구독 사용량 한도에 걸리면 작업이 멈춰요. 조금 뒤 "다시 시도"를 누르세요.
- 쇼츠는 대본까지만 만들어요.
