# brand/

이 폴더는 **처음 설정에서 분야를 고정하면 자동으로 채워집니다.** 배포본에는 이 안내 파일만 들어 있습니다.

| 파일 | 만드는 곳 |
|---|---|
| `pillars.json`, `brand.md`, `style-guide.md`, `channels.md`, `rules.md` | `studio-setup` 스킬 (분야 조사 + 문체 샘플 분석) |
| `feedback.md` | 프로그램 (화면에서 남긴 의견) |
| `corpus/` | 처음 설정에서 붙여 넣은 문체 샘플 |
| `character.png` (선택) | 직접 넣는 정사각형 캐릭터 이미지. 있으면 인스타 카드에 들어갑니다 |

만들어진 파일은 직접 고쳐도 됩니다. 다음 글부터 바로 반영됩니다.
