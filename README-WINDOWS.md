# 콘텐츠 스튜디오 (Windows)

분야만 정하면 블로그 글, 인스타그램 카드, 쓰레드 글을 만들어 주는 프로그램이에요. 이 컴퓨터 안에서만 돌아가고, 글쓰기는 Claude 유료 구독(Pro 또는 Max)으로 처리해요. 구독료 외에 추가 비용은 없고, 글을 쓸 때마다 구독 사용량이 줄어들어요.

개인이 만든 무료 프로그램이에요. Anthropic(Claude), Meta(인스타그램·쓰레드), 네이버와는 관계없어요(MIT 라이선스).

## 처음 한 번만: 설치

1. GitHub에서 받은 zip을 풀면 `content-studio-main` 폴더가 생겨요. 이름을 `content-studio`로 바꾸고 원하는 곳에 둬요. 예: `문서\content-studio`. **폴더를 옮기면 3번을 다시 해야 해요.**
2. 아래 두 가지가 필요해요.
   - **Node.js**: https://nodejs.org 에서 LTS 버전을 받아 설치해요.
   - **Claude Code**: 시작 메뉴에서 "PowerShell"을 열고 아래 한 줄을 붙여 넣고 Enter를 눌러요.
     ```
     irm https://claude.ai/install.ps1 | iex
     ```
     설치가 끝나면 PowerShell 창을 닫았다가 새로 열고 `claude` 를 입력해 Enter → 브라우저가 열리면 **Claude 구독 계정으로 로그인**해요. 로그인 뒤 PowerShell 창은 닫아도 돼요.
3. 이 폴더의 **`install.bat`** 을 더블클릭해요.
   - 필요한 프로그램과 로그인 상태를 확인해요. 빨간 **[필요]** 줄이 있으면 안내대로 해결하고 다시 실행해요.
   - 바탕화면에 **콘텐츠 스튜디오** 아이콘을 만들어요.
   - 마지막에 "매주 월요일 오전 7시에 주제 후보를 자동으로 만들까요?"에 `Y`를 누르면 월요일 아침마다 추천 주제를 새로 받아 둬요(최근 3일 안에 받은 추천이 있으면 건너뛰어요). 추천은 화면에서 언제든 직접 받을 수도 있어요.

> Windows가 "PC 보호" 창을 띄우면 "추가 정보" → "실행"을 누르세요. 개인이 만든 프로그램이라 서명이 없어서 나오는 창이에요.

## 매일 쓰기

- 바탕화면의 **콘텐츠 스튜디오** 를 더블클릭하면 앱 창이 열려요. (같은 기능: 폴더의 `start.bat`)
- 끄기: 폴더의 `stop.bat`. 끄지 않고 창만 닫아도 괜찮아요. 켜져 있어야 작업이 계속 진행돼요.

### 글 쓰는 순서

처음 켜면 안내 화면이 연결 확인, **분야 정하기**(예시 12개 중 고르거나 직접 입력), 글쓴이·말투, 문체 샘플(선택, 내가 쓴 글만)을 도와줘요. 분야는 한 번 고정하면 바꾸지 않아요. 고정하면 그 분야 맞춤 규칙을 5~10분 동안 만들고, 다 되면 글을 쓸 수 있어요. 그다음부터는 **홈** 맨 위의 "지금 할 일" 버튼만 따라가면 돼요. 글은 하루에 여러 편도, 며칠에 한 편도 괜찮아요.

1. **주제 정하기**: 쓰고 싶은 주제를 직접 넣거나, **추천 주제 받기**로 후보 12개(세부 분야에 고르게)를 받아 원하는 만큼 골라요. 추천은 언제든 새로 받을 수 있어요.
   - 진행 방식: 리서치 후 글쓰기(추천) / 리서치만 하고 저장 / 조사 없이 내 메모로 쓰기 / 한 번에 쓰기(빠름)
   - 숫자와 사실이 중요한 글(요금·기능 비교, 법·제도)은 **리서치 후 글쓰기**, 개념 설명이나 가벼운 글은 **한 번에 쓰기**가 맞아요.
   - 메모에 글 흐름을 줄마다 적고 **메모에 적은 흐름대로 쓰기**를 켜면 그 순서와 마무리대로 써요. 줄마다 사실인지 확인하고, 확인되지 않은 줄은 검수함에 "확인 필요"로 표시해요.
2. **자동 진행**: 리서치 → 초안 → 인스타 카드·쓰레드. 한 편에 10분 안팎 걸려요. 홈의 "쓰고 있는 글"에서 글마다 어느 단계인지 보여요.
3. **검수**: 초안을 읽고 **승인**하거나 **수정 요청**을 적어요. "출처 1곳", "확인 필요" 항목은 출처 링크로 확인해요. 인스타 표지 사진을 고르거나 **직접 찍은 사진**을 올릴 수 있어요.
4. **발행**: 제목·본문·태그를 복사해 블로그에 붙여 넣어요. 사진·도표·카드 이미지를 받아 올리고, 블로그 주소를 넣고 **발행 완료**를 눌러요. 쓰레드 글도 복사해서 올려요.

그 밖의 도구:
- **리서치 기록**: 리서치한 내용은 모두 이 컴퓨터에 쌓여요. 더 조사하거나, 추가 조사 없이 그 기록으로 바로 글을 쓸 수 있어요.
- **뉴스레터**: 원할 때 최근 7일 동안 승인·발행한 글을 모아 주간 노트를 만들어요.
- **의견 남기기**: 오른쪽 아래 주황 버튼이에요. 남긴 의견은 다음 작업부터 모든 글에 가장 먼저 반영돼요. 피드백 탭에서 끄거나 지울 수 있어요.
- **설정**: 고정한 분야 확인, 글쓴이 이름·계정·뉴스레터 주소·카드 색 변경, 연결 상태 확인, 처음 안내 다시 보기.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 아이콘을 눌러도 창이 안 떠요 | `install.bat` 을 다시 실행해 [필요] 항목을 확인해요 |
| 작업이 "실패"로 떠요 | 홈에서 "다시 시도"를 눌러요. 계속 실패하면 구독 사용량 한도일 수 있으니 시간이 지난 뒤 다시 해요 |
| "Claude에 로그인하지 않았어요" | PowerShell에서 `claude` 를 실행해 구독 계정으로 로그인해요 |
| "구독이 아닌 방식으로 로그인" 경고 | API 요금이 나갈 수 있어요. `claude` 를 실행한 뒤 `/login` 으로 구독 계정에 다시 로그인해요 |
| 카드 이미지가 안 나와요 | Microsoft Edge가 설치되어 있는지 확인해요 |
| 월요일 자동 추천을 끄고 싶어요 | PowerShell에서 `scripts\schedule-weekly.ps1 -Uninstall` |

결과물은 모두 `data` 폴더에 저장돼요(분야 `data\profile.json`, 추천 주제 `data\topics`, 글 `data\posts`, 리서치 `data\research`, 설정 `data\settings.json`). 분야 맞춤 규칙은 `brand` 폴더에 있어요. 이 폴더를 지우면 기록이 사라지니 주의하세요.

다른 분야도 쓰고 싶으면 이 폴더를 통째로 복사해 이름을 바꾸고(예: `content-studio-여행`), 복사한 폴더에서 `config.json`의 `port`를 다른 숫자(예: 4610)로 바꾼 뒤 `install.bat`을 다시 실행하세요.
